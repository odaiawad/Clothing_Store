# موقع شركة التسويق والتصميم (RTL)

موقع هبوط عربي حديث وخفيف بتقنيات HTML/CSS/JS فقط.

## البدء
- افتح الملف `index.html` مباشرة في المتصفح، أو شغّل خادم بسيط:
```bash
python3 -m http.server 8080 --directory /workspace
```

## التخصيص
- الاسم والشعار: عدّل النص داخل عنصر `brand` في `index.html`.
- بيانات التواصل: داخل تذييل الصفحة في `index.html`.
- البريد المستقبل للنموذج: استبدل `hello@example.com` داخل `assets/js/main.js`.
- الهوية والألوان: غيّر المتغيرات داخل `assets/css/style.css`:
```css
:root {
  --primary: #0ea5e9;
  --accent: #22c55e;
}
```
- الصور: تم استخدام صور من Unsplash و dummyimage، استبدل الروابط بما يناسبك.

## البنية
- `index.html`: الصفحة الرئيسية مع أقسام: الخدمات، الأعمال، آلية العمل، العملاء، من نحن، تواصل.
- `assets/css/style.css`: أنماط حديثة مع دعم RTL بالكامل.
- `assets/js/main.js`: قائمة الجوال، تمرير سلس، وتجهيز نموذج مراسلة.

## النشر
- أي استضافة ملفات ثابتة (Netlify, Vercel, GitHub Pages، أو خادمك الخاص).
