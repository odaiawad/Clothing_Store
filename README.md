# شركة الإبداع للتسويق والتصميم | Creative Marketing & Design

موقع ويب حديث ومتجاوب لشركة تسويق وتصميم، مصمم باللغة العربية مع دعم كامل لاتجاه النص من اليمين إلى اليسار (RTL).

## ✨ المميزات

### 🎨 التصميم
- تصميم حديث وأنيق مع انحدارات لونية جذابة
- دعم كامل للغة العربية واتجاه RTL
- تصميم متجاوب لجميع أحجام الشاشات
- رسوم متحركة سلسة وتأثيرات بصرية
- استخدام خط Cairo الجميل للنصوص العربية

### 📱 الاستجابة والتفاعل
- قائمة تنقل متجاوبة مع قائمة جانبية للموبايل
- تمرير سلس بين الأقسام
- رسوم متحركة عند التمرير (Scroll Animations)
- تصفية تفاعلية لأعمال الشركة
- نماذج تفاعلية مع تحقق من صحة البيانات

### 🚀 الأقسام الرئيسية

#### 1. القسم الرئيسي (Hero Section)
- عنوان جذاب مع نص متدرج الألوان
- أزرار دعوة للعمل
- رسوم متحركة طافية تمثل الخدمات

#### 2. قسم الخدمات
- 4 خدمات رئيسية:
  - تطوير المواقع الإلكترونية
  - التسويق الرقمي
  - التصميم الجرافيكي
  - التطبيقات المحمولة
- كل خدمة مع أيقونة مميزة وقائمة تفصيلية

#### 3. قسم الأعمال (Portfolio)
- تصفية تفاعلية حسب نوع العمل
- عرض للمشاريع مع أوصاف تفصيلية
- تصميم بطاقات أنيق مع تأثيرات عند التمرير

#### 4. قسم "من نحن"
- نبذة عن الشركة
- إحصائيات متحركة:
  - 50+ مشروع مكتمل
  - 30+ عميل راضي
  - 5+ سنوات خبرة
  - دعم فني 24/7

#### 5. قسم التواصل
- نموذج تواصل شامل مع تحقق من البيانات
- معلومات التواصل (عنوان، هاتف، بريد إلكتروني)
- روابط وسائل التواصل الاجتماعي

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكل الموقع الأساسي
- **CSS3**: التصميم والرسوم المتحركة
  - CSS Grid & Flexbox للتخطيط
  - CSS Animations & Transitions
  - Media Queries للاستجابة
- **JavaScript (ES6+)**: التفاعل والوظائف
  - Intersection Observer API للرسوم المتحركة
  - Form Validation
  - Touch Gestures للموبايل
- **Font Awesome**: الأيقونات
- **Google Fonts**: خط Cairo العربي

## 🚀 كيفية التشغيل

### متطلبات النظام
- متصفح ويب حديث
- خادم ويب محلي (اختياري للتطوير)

### خطوات التشغيل

1. **تحميل الملفات**
   ```bash
   git clone [repository-url]
   cd creative-marketing-website
   ```

2. **فتح الموقع**
   - افتح ملف `index.html` مباشرة في المتصفح
   - أو استخدم خادم محلي:
   ```bash
   # باستخدام Python
   python -m http.server 8000
   
   # باستخدام Node.js (npx)
   npx serve .
   
   # باستخدام PHP
   php -S localhost:8000
   ```

3. **عرض الموقع**
   - افتح المتصفح واذهب إلى `http://localhost:8000`

## 🎨 التخصيص

### تغيير الألوان
في ملف `styles.css`، يمكنك تعديل المتغيرات اللونية:

```css
/* الألوان الرئيسية */
:root {
  --primary-gradient: linear-gradient(45deg, #667eea, #764ba2);
  --secondary-color: #2c3e50;
  --text-color: #333;
  --light-bg: #f8f9fa;
}
```

### تحديث المحتوى
1. **معلومات الشركة**: عدّل النصوص في `index.html`
2. **معلومات التواصل**: حدّث الهاتف والبريد الإلكتروني والعنوان
3. **وسائل التواصل**: أضف روابط حساباتك الفعلية

### إضافة مشاريع جديدة
في قسم Portfolio، أضف عناصر جديدة:

```html
<div class="portfolio-item" data-category="websites">
    <div class="portfolio-image">
        <img src="project-image.jpg" alt="اسم المشروع">
    </div>
    <div class="portfolio-content">
        <h3>اسم المشروع</h3>
        <p>وصف المشروع</p>
        <div class="portfolio-tags">
            <span>تقنية 1</span>
            <span>تقنية 2</span>
        </div>
    </div>
</div>
```

## 📧 تكامل نموذج التواصل

حالياً، النموذج يحفظ البيانات محلياً في `localStorage`. لتفعيل الإرسال الفعلي:

### 1. استخدام خدمة خارجية
```javascript
// في script.js، استبدل دالة simulateFormSubmission
async function submitToService(formData) {
    const response = await fetch('https://formspree.io/f/YOUR-FORM-ID', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
        },
        body: JSON.stringify(formData)
    });
    return response.json();
}
```

### 2. استخدام خادم خاص
```javascript
async function submitToServer(formData) {
    const response = await fetch('/api/contact', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
        },
        body: JSON.stringify(formData)
    });
    return response.json();
}
```
